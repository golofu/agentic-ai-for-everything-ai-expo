01.1 · หน้าตาโปรแกรม

วันนี้เราใช้ 2 โปรแกรมนี้ หน้าตาจริงเป็นแบบนี้

Claude Desktop → แท็บ Code (ปุ่ม </> มุมซ้ายบน)

  • กล่องพิมพ์ "Describe a task" สั่งเป็นภาษาไทยได้เลย
  • มุมขวาล่าง: โมเดล (Opus 5.5) และโหมด (Auto)

  • ปุ่มโฟลเดอร์ใต้หัวข้อ = เลือกโฟลเดอร์งาน
  • กล่องพิมพ์ "Ask Codex anything" พิมพ์ @ เพื่อแนบไฟล์
  • แถวล่าง: สิทธิ์ (Full access) และโมเดล

01.1

Myth vs Reality

ความเชื่อความจริง
Claude Code ต้องเขียน code เป็นไม่ต้องเลย สั่งงานด้วยภาษาไทยได้ 100% คำว่า Code ในชื่อหมายถึง AI ทำ code ให้คุณ ไม่ใช่คุณต้องเขียนเอง
Terminal ยากและน่ากลัวTerminal คือแค่กล่องพิมพ์ข้อความ เหมือน chat box แต่คุยกับ AI ที่ทำงานได้จริงบนเครื่องคุณ
เหมาะกับ Developer เท่านั้นปี 2026 มีหนังสือสำหรับ solopreneurs มีคนสร้าง startup ได้ MVP ใน 48 ชั่วโมง โดยไม่เขียน code สักบรรทัด
ใช้ ChatGPT หรือ Claude เว็บก็เหมือนกันต่างกันมาก เว็บคือถาม-ตอบแล้วคุณไปทำเอง Terminal คือมีลูกน้องนั่งอยู่ที่โต๊ะ เปิดไฟล์ ทำงาน และส่งงานให้เสร็จ

วันนี้ไม่ต้องเปิด Terminal เลย ใช้แอป Claude Desktop (แท็บ Code) และ ChatGPT Desktop (Codex) แทน

01.2

The AI Spectrum: เว็บ / แชทในแอป / Code

บทบาทที่ปรึกษาอยู่อีกห้องเพื่อนร่วมงานบนจอลูกน้องที่นั่งคุมเครื่องคุณ
การเข้าถึงไฟล์อัปโหลดทีละไฟล์ลากวางทีละไฟล์อ่านทั้งโฟลเดอร์ หลายร้อยไฟล์พร้อมกัน
ความจำลืมทุกครั้งที่เริ่มใหม่จำได้แค่ใน session เดียวCLAUDE.md ไฟล์ความจำถาวร

ทำงานอัตโนมัติทำไม่ได้ตั้งเวลาได้แต่ต้องเปิดเครื่องทิ้งไว้Routines ทำงานบนคลาวด์ ข้ามคืน

ตัวตัดสินว่าใครทำงานฉลาด ไม่ได้ขึ้นอยู่แค่ความเก่งของโมเดล
แต่ขึ้นอยู่กับความสามารถในการเชื่อมต่อโปรแกรมอื่น ๆ ได้อย่างเนียนกริ๊ป

01.2

Code เหมาะกับงานแบบไหน

Claude.ai + ChatGPT Workเหมาะกับงานของพนักงานออฟฟิศและเจ้าของกิจการทั่วไป
Claude Code + Codexเหมาะกับการสร้างเว็บ แอป และเกมต่าง ๆ
Claude Code / Codex ทะลุทะลวงกว่า เพราะAI ลงมือทำงานในคอมเราได้เองแทบทุกขั้น ตั้งแต่สร้างจนใช้งานจริง
1 · เปิดแอปลองกดได้ทันที

AI เปิดแอปขึ้นมาเอง ลองกด "บันทึกน้ำหนัก" กรอกเลขจริง เจอปุ่มที่กดไม่ได้ก็แก้เองจนใช้ได้

2 · เซฟจุดย้อนกลับได้

สั่งเพิ่มหน้ารายงานแล้วแอปพัง พิมพ์ว่า "ย้อนกลับไปจุดเซฟเมื่อกี้" แอปกลับมาใช้ได้เหมือนเดิม

3 · เห็นว่า AI แก้อะไรไปบ้าง

สั่งเปลี่ยนสีปุ่ม แต่ AI ไปแก้หน้าอื่นด้วย เราเห็นทันทีก่อนกดยอมรับ

4 · สั่งรันคำสั่งในเครื่องได้

สั่ง "เอาขึ้นเว็บให้หน่อย" AI รันคำสั่งเอง ได้ลิงก์ส่งให้คุณแม่เปิดในมือถือ

ที่มา: Claude Academy (Choosing between Cowork or Chat) · Claude Code Docs (Desktop: Browser pane, Git, diff view, terminal)

01.3

The Engine: สมอง + มือ

CLAUDE.md = สมองไฟล์ข้อความในโฟลเดอร์งาน Claude อ่านเองทุก session เหมือนคู่มือพนักงานใหม่ · ระบุธุรกิจ ลูกค้า tone สิ่งที่ห้ามทำ · เขียนครั้งเดียว ใช้ได้ตลอด (วันนี้ prompt บท 02 สร้างให้)
MCP = มือเชื่อม Claude Code กับ Notion, Google Calendar, Gmail, Figma, ฐานข้อมูล · สั่งงานข้ามแพลตฟอร์มจากที่เดียว · ไม่ต้องตั้งวันนี้ ค่อยเพิ่มเมื่อเจอปัญหา (ดูคำศัพท์บท 06)
