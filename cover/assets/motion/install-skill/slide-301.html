วิธีติดตั้ง Skill

ได้ไฟล์ Skill มาแล้ว ติดตั้งได้ทั้ง Claude และ ChatGPT

Claude

เมนู: การปรับแต่ง → Skills → + เพิ่ม

อัปโหลดไฟล์ .zip

  1. อัปโหลด Skill — เลือกไฟล์ .zip (ทางหลัก)
  2. สร้าง Skill — เขียนเอง
  3. สร้างด้วย Claude — คุยให้ Claude สร้างให้
  4. ผ่านแชท — แนบไฟล์หรือวางข้อความ แล้วสั่ง “ติดตั้ง skill นี้ให้หน่อย” กดบันทึก
  5. Record a skill — อัดหน้าจอทำงานให้ดู (Claude Desktop บน Mac)

ChatGPT

เมนู: ปลั๊กอิน → ทักษะ → เพิ่ม

อัปโหลดไฟล์ .zip

  1. อัปโหลดจากคอมพิวเตอร์ — ลากไฟล์ .zip มาวาง (ทางหลัก)
  2. สร้างด้วยแชท
  3. สร้างด้วยเครื่องมือแก้ไข
  4. ผ่านแชท — แนบไฟล์หรือวางข้อความ แล้วสั่ง “ติดตั้งเป็น skill ใน ChatGPT ให้หน่อย”

หน้าถัดไปมีภาพจริงทีละขั้น
