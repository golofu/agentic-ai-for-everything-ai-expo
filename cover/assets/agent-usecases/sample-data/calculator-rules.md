# กติกาคิดราคาตัวอย่าง
ใช้ราคาต่อชิ้นจาก products.csv
รวมยอด = ผลรวมของ จำนวน x ราคาต่อชิ้น
ถ้ายอดสินค้ารวมต่ำกว่า 1000 บาท ค่าส่ง 60 บาท; ตั้งแต่ 1000 บาท ค่าส่ง 0 บาท
ไม่คิดส่วนลดหรือภาษีเพิ่ม เพราะไม่มีข้อมูลให้
จำนวนต้องเป็นจำนวนเต็มตั้งแต่ 0 ขึ้นไป
ตัวอย่าง: สมุด 2 เล่มและกระเป๋า 1 ใบ = 670 + ค่าส่ง 60 = 730 บาท
