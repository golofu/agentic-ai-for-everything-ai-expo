# นโยบายตัวอย่าง
จัดส่งภายใน 3 วันทำการหลังยืนยันชำระเงิน
เปลี่ยนสินค้าที่เสียหายจากการจัดส่งได้ภายใน 7 วันหลังรับสินค้า โดยส่งรูปและเลขคำสั่งซื้อ
การคืนเงินในกรณีอื่น: ยังไม่มีข้อมูลอนุมัติ
ราคาองค์กร: ต้องขอข้อเสนอจากทีมขาย ห้ามคำนวณส่วนลดเอง
ห้ามส่งข้อความหาลูกค้าจนกว่าผู้รับผิดชอบตรวจและอนุมัติร่าง
