# ขอรับพนักงานใหม่

ตำแหน่ง: เจ้าหน้าที่ประสานงานลูกค้า (Customer Coordinator)
จำนวน: 1 อัตรา
เงินเดือน: 18,000–22,000 บาท ตามประสบการณ์
เริ่มงาน: 1 ธันวาคม 2569
สถานที่: สำนักงานกรุงเทพ ทำงานจันทร์–ศุกร์ 9.00–18.00 น.

หน้าที่หลัก
- รับโทรศัพท์และไลน์ลูกค้า ตอบคำถามสินค้า ส่งต่อให้ฝ่ายขายเมื่อเป็นออเดอร์ใหญ่
- ออกใบเสนอราคาและติดตามสถานะการจัดส่ง
- สรุปปัญหาลูกค้าประจำสัปดาห์ให้หัวหน้าทีม

คุณสมบัติ
- ประสบการณ์งานบริการลูกค้าหรือประสานงาน 1 ปีขึ้นไป
- ใช้ Excel และ Google Sheets ได้
- พิมพ์ภาษาไทยเร็ว สื่อสารสุภาพ ใจเย็น
- ถ้าเคยใช้ AI ช่วยงานจะพิจารณาเป็นพิเศษ
