# แนวทางแบรนด์
ชื่อ: BAAN LAMUN / บ้านละมุน
บุคลิก: เรียบง่าย อบอุ่น ใช้งานจริง
สี: เขียว #276B5B, ครีม #F5F1E7, น้ำตาล #846B55
ภาษา: ภาษาไทยสั้นและชัดเจน
กลุ่มลูกค้า: คนทำงาน 25–45 ปี และทีมจัดซื้อขององค์กร
ข้อความหลัก: โต๊ะทำงานที่พร้อมสำหรับทุกวัน
ภาพ: ฉากโต๊ะไม้ แสงธรรมชาติ พื้นที่ว่างสำหรับข้อความ
ห้ามเติมคุณสมบัติที่ไม่ได้อยู่ในข้อมูลสินค้า
