ทำครั้งเดียว ได้โฟลเดอร์ที่มีคลังของแบรนด์ ที่เก็บโปรเจกต์ และกติกาให้ Claude อ่านเอง ต่อไปแค่เปิดโฟลเดอร์นี้แล้วพิมพ์สั่งงานเป็นภาษาไทย

1สร้างโฟลเดอร์ว่าง 1 โฟลเดอร์ไว้ที่ที่หาง่าย เช่น Downloads, Documents หรือไดรฟ์ C ตั้งชื่ออะไรก็ได้ เช่น AI-Work
2เปิด Claude Desktop ไปที่แท็บ Code

5ถ้า Claude ขออนุญาตสร้างไฟล์หรือรันคำสั่ง ให้กดอนุญาต รอราว 1–2 นาที
6AI จะรายงานว่าสร้างโฟลเดอร์ motion-graphic-workspace เสร็จ และติดตั้ง three.js กับ Lottie แล้ว จากนั้นไปใส่ของแบรนด์ลง resources/ และกรอก brand.md
